# Development roadmap after release 0.3

Delivered: shared accounting/storage/control services and usable initial workflows for all eight modules. Follow docs/REQUIREMENTS-COVERAGE.md for per-feature limits.

1. Validate golden accounting data and provider-specific grouping with a qualified finance advisor and design partners.
2. Certify live read-only NetSuite/Business Central mappings, source completeness, permissions, token rotation and incremental reconciliation.
3. Add enterprise identity, database RLS, migration rehearsal, secrets vault and object storage with independent integrity anchors.
4. Evaluate model investigations against labeled real discrepancies; monitor unsupported narratives and reviewer acceptance before expansion.
5. Harden close workflows, notifications, materiality/period controls, and safe idempotent posting after approved separation-of-duty tests.
6. Add statistical cash calibration and forecast-versus-actual comparisons from verified bank/AR/AP data.
7. Extend consolidation for ownership, non-controlling interests, historical equity and CTA accounting under finance-domain review.
8. Add distributed orchestration, monitoring, backup restoration, security testing and enterprise procurement readiness.

The current release does not convert an illustrative $200,000/9-month business blueprint into an assured enterprise launch by itself.
